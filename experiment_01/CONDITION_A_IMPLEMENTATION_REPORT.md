# Experiment 1 — Condition A implementation report

## Status

Condition A output generation is complete. The selected host model was used without adaptation,
training, auxiliary supervision, or parameter updates. Three leakage-safe test items were synthesized:
YT0028, YT0029, and YT0030. Condition B has not begun.

The primary perceptual evaluation is complete as a single-rater feasibility pilot. Mary Adelua, a
fluent Yoruba speaker and the dataset speaker, reported correct pronunciation, tone, intelligibility,
and meaning for all three outputs. Naturalness was rated partial for all three, with the note that it
can be better.
The ratings are recorded in `artifacts/experiment_01/condition_a/human_evaluation_items.csv` and
summarized in `human_evaluation_summary.json`. Automated checks remain pipeline diagnostics and were
not substituted for the frozen human pronunciation criteria.

## Implementation issues and unresolved protocol gates

1. **Signed release not yet filed.** The protocol names a signed release as a precondition. The current
   run is therefore a local, non-release research checkpoint; generated files must not be presented as
   a formally released dataset experiment until that gate is satisfied.
2. **No NVIDIA GPU is exposed locally.** Condition A inference completed reproducibly on CPU. This did
   not change any frozen setting because Condition A performs no training. A GPU will be needed before
   later adaptation conditions can be run efficiently.
3. **Primary evaluation is single-rater and non-blinded.** Segmental pronunciation, lexical tone,
   intelligibility, meaning recovery, and naturalness were rated by the fluent dataset speaker. The
   project deliberately does not convert audio integrity, ASR, duration, or F0 diagnostics into primary
   scores, but independent blinded raters remain necessary for stronger evidence.
4. **Verified phoneme labels are unavailable.** The frozen protocol requires human-verified labels for
   its phoneme/segmental endpoint. Current phoneme candidates remain automatically generated and masked
   off, so that endpoint cannot yet receive a defensible label-based score.
5. **Naturalness margin is not numerically declared.** The protocol requires a predeclared
   non-inferiority margin but the repository does not currently contain a numeric threshold. No margin
   was invented during implementation.
6. **Small held-out set and partial ceiling effect.** Three test utterances are leakage-safe but support
   only a feasibility pilot. Pronunciation, tone, intelligibility, and meaning scored 100%; naturalness
   was partial for every item and therefore retains room for improvement.
7. **Windows model cache warning.** Hugging Face fell back from symlink/Xet optimizations to ordinary
   HTTP caching. This affected download efficiency only; the resolved model commit and output hashes
   are recorded.

## Gate before Condition B

The Condition A fluent-listener ratings have been imported. Before Condition B, explicitly acknowledge
that the three-item baseline has a ceiling effect on pronunciation, tone, intelligibility, and meaning.
Naturalness remains differentiable. For a formally protocol-complete experiment, also resolve the
signed-release, verified-phoneme-label, and numeric naturalness-margin gates.
