# Microsoft Copilot Voice — matched Pilot 3 benchmark

## Purpose

This test applies the exact ChatGPT Pilot 3 prompts and evaluation criteria to Microsoft Copilot Voice. The system is assigned comparison code `S02` for later blinded review.

## Recording procedure

1. Open Microsoft Copilot and start Copilot Voice.
2. Select one voice and keep it unchanged for all ten prompts.
3. Start one continuous Windows screen recording with system audio.
4. Submit each prompt separately and wait until Copilot completely finishes speaking.
5. Wait silently for five seconds before submitting the next prompt.
6. Do not speak during the recording.
7. Do not correct or retry errors; preserve them as benchmark evidence.
8. Upload the completed MP4 to Codex.
