# ChatGPT Voice Pilot 3 — tone generalization test

## Purpose

Pilot 3 tests ten new sentences, emphasizing meaning-changing Yoruba tones. It uses the same one-sentence-per-turn procedure as Pilot 2 so the results can be compared directly.

## Recording procedure

1. Use the same ChatGPT voice and voice mode used for Pilot 2.
2. Start one continuous screen recording with system audio.
3. Submit each prompt separately and wait until ChatGPT completely finishes speaking.
4. Wait silently for five seconds before submitting the next prompt.
5. Do not speak during the recording.
6. If ChatGPT makes an error or adds speech, do not restart; preserve it as test evidence.
7. Upload the completed MP4 to Codex.
