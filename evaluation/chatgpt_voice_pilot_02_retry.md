# ChatGPT Voice pilot 02 — one sentence per turn

## Why this retry is different

Pilot 1 sent ten sentences in one request, and its output could not be matched to the requested Yoruba sentences. Pilot 2 sends one sentence at a time. This makes each response independently identifiable and allows pronunciation and tone evaluation.

Pilot 1 remains archived and will not be mixed with Pilot 2 results.

## Before recording

Write down:

- ChatGPT voice name:
- Voice mode shown, if any (Live, Advanced, or Standard):
- Account plan, if known:
- Browser:
- Test date:

Keep the same voice and mode for all ten sentences.

## Recording procedure

1. Open one new ChatGPT conversation at `chatgpt.com`.
2. Start ChatGPT Voice and choose one voice.
3. Press `Windows + G`, open **Capture**, and begin recording with system audio.
4. Paste **Prompt 1** below and let ChatGPT finish speaking.
5. Wait silently for five seconds.
6. Paste **Prompt 2**, let it finish, and wait another five seconds.
7. Continue until Prompt 10 is complete.
8. Stop the Game Bar recording.
9. Upload the single resulting MP4 file to Codex.

Do not speak during ChatGPT's responses. If ChatGPT adds an explanation, do not restart; keep recording so the failure is preserved in the test.

## What Codex will do after upload

1. Extract the system audio from the MP4.
2. Split the ten responses using the five-second gaps.
3. Assign the fixed prompt IDs in order.
4. Check file quality and duration.
5. Compare each output with the verified Yoruba reference.
6. Present the ten ChatGPT outputs for fluent-speaker review.
7. Calculate target coverage, transcript accuracy, tone-contrast preservation, meaning recovery, and naturalness findings that the available evidence supports.
